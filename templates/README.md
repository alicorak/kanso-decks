# Templates

The approved copy for each deck and document type, as the skill's copy step produces it. A build fills these
placeholders per client; nothing here is client-specific and no real fee, company or bank detail belongs in this
folder.

| File | Covers |
|---|---|
| `intro-deck-copy.md` | Intro deck |
| `proposal-copy.md` | Proposal, shared slides plus the four service variants |
| `kickoff-copy.md` | Kickoff deck, shared slides plus the two variant slides |
| `invoice-copy.md` | Proforma invoice, project milestone and retainer |

Change the copy here and in `plugins/kanso-decks/skills/kanso-decks/references/` together: the references are what
the skill follows, these files are what a finished document reads like.
