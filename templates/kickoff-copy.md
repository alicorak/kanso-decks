# Kanso — Kickoff template · Copy

Generated with the `kanso-decks` skill, step 3. Deck type: kickoff (template) · Theme: dark · Language: English · UI v2.
11 slides: 9 shared + 2 variant (06 Plan and 09 What we need from you, for Brand, Mobile app, End-to-end, Website).
A finished kickoff = shared slides + one service's variant slides, in slide-number order (11 slides).

Conventions
- Layer names match `references/figma-system.md` (UI v2). **Header** = section label. **Footer** = footer Meta.
- `[brackets]` = placeholder, filled per project. Body and list text are written in sentence case; the layouts render them uppercase.
- Footer on every slide except the cover: **Confidential — prepared for [Client]**. Page numbers `NN / 11`.
- The kickoff does not sell again: no fee, no signing, no case studies. Scope and timeline come from the signed proposal.
- Kickoff happens within **5 days** of signing (Kanso standard).
- Process phases are always Strategy · Design · Development · Support.
