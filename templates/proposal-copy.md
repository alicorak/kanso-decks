# Kanso — Proposal template · Copy

Generated with the `kanso-decks` skill, step 3. Deck type: proposal (template) · Theme: dark · Language: English · UI v2.
33 slides: 9 shared + 24 variant (6 each for Brand, Mobile app, End-to-end, Website).
A finished proposal = shared slides + one service's variant slides, in slide-number order (14–15 slides).

Conventions
- Layer names match `references/figma-system.md` (UI v2). **Header** = section label. **Footer** = footer Meta.
- `[brackets]` = placeholder, filled per client. Body and list text are written in sentence case; the layouts render them uppercase.
- Footer on every slide except the cover: **Confidential — prepared for [Client]**.
- Process phases are always Strategy · Design · Development · Support; only the work inside them changes.
